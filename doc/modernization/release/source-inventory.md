# Source and license inventory

This inventory covers every tracked path by ordered groups instead of a
per-file hash list. The first matching row controls when groups overlap.
It records provenance evidence, known terms, local changes, and build use; it
does not make a legal conclusion.

`REUSE.toml` is the machine-readable counterpart to these groups. It uses
override annotations for Autoconf outputs, GNU config helpers, `install-sh`,
and archived lcc documentation so their specific terms take precedence over
the surrounding historical-source group.

## Evidence boundary

The explicit MIT grant in `LICENSES/MIT.txt` covers only standalone
modernization files identified by `REUSE.toml`. Modernization changes within a
historical file, and new architecture code derived from a historical
implementation, inherit that file's Tick-C and lcc terms. The presence of
GPL-covered configuration helpers does not relicense unrelated files. Exact
notices must be retained. File-level metadata uses the stable custom
identifiers `LicenseRef-TCC-1996` and `LicenseRef-LCC-1994` where the historical
conditions apply rather than replacing them with MIT.
